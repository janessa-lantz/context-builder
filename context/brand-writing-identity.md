# Brand Writing Identity

How the company sounds. The verbal counterpart to [brand-visual-identity.md](brand-visual-identity.md). Skills read both so every generated asset sounds and looks like the company. Entries are verbatim from a live surface (source noted) or human synthesis (`source: human`); the LLM never overwrites a human-authored entry.

## Lexicon
*(coined or redefined terms and key concepts, as term: definition or usage rule; banned phrases belong in Guardrails)*

Deployment: **Mintlify** — extracted from live surfaces, setup run 2026-07-07.

- **knowledge infrastructure**: the category coin; what documentation becomes when agents build on it (homepage hero, contact-sales)
- **self-updating documentation / self-updating knowledge systems**: docs that evolve from code changes and signals without human upkeep; the flagship product promise (homepage, POV essay, autopilot post)
- **autonomous knowledge management**: the emerging product category the POV essay names and claims (blog-documentation-is-dead)
- **the knowledge layer / "The New Knowledge Layer"**: the architectural slot Mintlify claims — "the knowledge layer that makes products understandable, usable and discoverable by AI agents" (POV essay, series-b)
- **agent-native**: built for agents as first-class readers, one step past "AI-native" (homepage "Agent-native platform")
- **the agent web**: the web whose traffic is increasingly agents, which docs must scale with (homepage "Built to scale with the agent web")
- **intent layer**: documentation that encodes the reasoning behind decisions, not just implementation (structured-docs essay)
- **context layer**: docs as the abstraction between coding agents and the codebase (structured-docs essay)
- **documentation debt**: the maintenance backlog the Agent products attack, by analogy to tech debt (agents-launch post)
- **GTM engineer**: what Mintlify calls its sales-side counterpart — CTAs say "Talk to a GTM engineer," never "talk to sales" (use-case pages)
- **llms.txt / LLMs-full.txt**: the docs-for-LLMs index format, co-developed with Anthropic; referenced as a named standard (anthropic case study, library comparison)

Note: the lexicon is agent-era heavy and thin on inherited docs-industry vocabulary
(docs-as-code, RAG, MCP are industry terms Mintlify uses but did not coin) — that is the
honest shape, not a gap padded over.
